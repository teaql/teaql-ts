# 0.2.8: default log privacy

Tracking: https://github.com/teaql/teaql-ts/issues/34

Includes the default log redaction and exact plaintext acknowledgement described
in [0.2.7](0.2.7.md), plus production-built browser smoke verification.

The 0.2.7 publication stopped before npm publish: Jest's `toThrow` did not
recognize a rejected native SQLite exception in the hosted test environment.
The canary now asserts its exact `SQLITE_CONSTRAINT_PRIMARYKEY` code, retaining
the rejection requirement and unchanged-row assertion. The old tag is not moved.

Local full suite: 141 passed, 2 skipped. Hosted release tests and public package
resolution must succeed before publication is reported complete.

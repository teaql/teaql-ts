# TeaQL TypeScript 0.3.0

Tracking: [release issue 46](https://github.com/teaql/teaql-ts/issues/46).

This release brings the merged request intent and Trace Chain implementation
to the public package. It includes query and mutation lineage, independent
graph ownership, relation aggregates, facet tracing and safe SQL diagnostics.
Generated-library examples cover shared references, partial relation loading,
Checker overlap, stream capture and repeat bootstrap behavior.

Regenerate applications when upgrading from 0.2.x: request and lineage
contracts have changed. Logging remains enabled by default, with existing
disable controls and sensitive-parameter masking preserved.

Release gates are the complete local example inventory, native tests,
an isolated consumer of the immutable internal 0.3.0 package, and public
package delivery checks. External-provider skips remain explicit; this
release does not claim complete TFP or every enterprise database support.

# TypeScript 0.3.1

Tracking: [TypeScript #51](https://github.com/teaql/teaql-ts/issues/51) and
[conformance #109](https://github.com/teaql/teaql-conformance/issues/109).

The optional Node standard telemetry module uses trusted environment activation
and reports enabled/disabled startup settings. Supported runtime operations
produce full safe traces, metrics and logs without per-method instrumentation.
Expanded SQL stays masked, and each completion carries its own physical identity.
Owned SDK queues, acknowledgement handling and finite shutdown preserve customer
globals, business outcomes and independent audit.

Node telemetry is not enabled in browser SQLite or Expo. Regenerate libraries to
retire the separate page terminal and adopt the current request-tree/search metadata;
use ordinary list execution with offset/limit and explicit count when needed.

The conformance `2026-10-13-standard-telemetry-onboarding` report retains source and
internal-candidate tests. Signed-tag, final-package and public-consumer verification
are separate gates, not inferred from those candidate results.
